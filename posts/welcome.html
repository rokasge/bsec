Opening the log

2026-09-11 · meta · 2 min

This is where research notes, disclosed vulnerabilities, and technical write-ups will land. Nothing here yet that you couldn't guess.

What goes here

Three kinds of post, roughly:

  • Disclosure write-ups — published only once a fix has shipped or the disclosure window has expired
  • Research notes — techniques, tooling, and things that took longer to figure out than they should have
  • Advisories — CVE coordination output and vendor acknowledgements

What does not

No exploit code before a patch exists. No vendor still in an active disclosure window. No client names without written permission.

If it isn't fixed, it isn't published.

How this site is built

Static HTML, hand-written. One shared stylesheet, no build step, no frameworks, no analytics, and no javascript. The whole site is a handful of files you could read in a minute.

That is deliberate. A security research site that ships a JavaScript bundle to display plain text is making an argument it probably doesn't want to make.
